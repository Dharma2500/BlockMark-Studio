# BlockMark Studio

Клиентский мод для Minecraft Java Edition 1.21.11 + Fabric. Он добавляет закреплённые в мировых координатах неоновые измерительные стрелки, 3D-контуры областей и плавающие подписи для записи обучающих роликов.

## Возможности

- Стрелка между двумя выбранными блоками с автоматическим расчётом расстояния и заметной, принудительно отображаемой подписью в центре.
- 3D-контур после выбора противоположных углов области с автоматически рассчитанными шириной × глубиной × высотой.
- Толстые яркие двусторонние бирюзовые стрелки с белой сердцевиной и заметным контуром через блоки.
- Неоновый эффект без шейдеров и ресурспаков. Пользовательские подписи доступны дополнительно через команду.
- Сохранение отметок отдельно для каждого мира или сервера и измерения.
- Клиентский мод: устанавливать его на сервер не требуется.
- Автоматическая сборка JAR через GitHub Actions.

## Как скачать JAR

1. Открой вкладку Actions в этом репозитории.
2. Выбери последний успешный запуск Build BlockMark Studio.
3. Внизу страницы скачай артефакт blockmark-studio-jar. Это ZIP с готовым JAR.
4. Распакуй ZIP и помести JAR в папку mods своего профиля Minecraft.

## Установка

1. Установи Fabric Loader для Minecraft 1.21.11.
2. Установи Fabric API для Minecraft 1.21.11.
3. Помести JAR BlockMark Studio и JAR Fabric API в папку mods.
4. Запусти Minecraft с профилем Fabric 1.21.11.

## Горячие клавиши по умолчанию

- K (по умолчанию): укажи начальный блок, затем нажми ту же клавишу на конечном блоке.
- J (по умолчанию): выбери первый угол области, затем нажми ту же клавишу на противоположном углу.
- Backspace: удалить последнюю отметку.
- B: показать или скрыть все отметки.

**Переназначение:** открой Настройки → Управление → Назначение клавиш и найди категорию BlockMark Studio. Щёлкни по действию и нажми удобную клавишу. Конфликты подсвечиваются стандартным меню Minecraft. У мода больше нет бесполезного действия «добавить LABEL» на клавише M.

После создания стрелки расстояние автоматически появляется по центру линии. После создания области в центре контура отображаются её размеры в блоках. Обычная подпись не нужна для измерений; пользовательскую подпись можно добавить командой `/blockmark label ТЕКСТ`.

## Команды

Команды клиентские, вводятся в чате:

- /blockmark label ТЕКСТ — добавить подпись над выбранным блоком. Например: /blockmark label ВХОД ВОДЫ
- /blockmark rename ТЕКСТ — изменить последнюю подпись.
- /blockmark undo — удалить последнюю отметку.
- /blockmark clear — удалить все отметки текущего мира или сервера.
- /blockmark toggle — показать или скрыть отметки.
- /blockmark list — вывести число сохранённых отметок.

## Хранение

Файлы JSON сохраняются в config/blockmark-studio. Для каждого одиночного мира или адреса многопользовательского сервера создаётся отдельный файл. Координаты привязаны к измерению, где была создана отметка.

## О сборке

Workflow GitHub Actions собирает проект с Gradle и Java 25 как runtime, а байткод мода остаётся совместимым с Java 21.

Важно: многослойные бирюзовые линии имитируют свечение, но это не физический bloom-эффект. Основная линия учитывает стены, а дополнительный контур рисуется отдельным полупрозрачным проходом без проверки глубины.

Этот проект не является официальным продуктом Minecraft и не связан с Mojang или Microsoft.


## Статус

Исходный код собирается через GitHub Actions. Последняя успешная сборка доступна как артефакт запуска workflow во вкладке Actions.
